# FP&A Financial Model

A dynamic Financial Planning & Analysis (FP&A) model built in Excel, featuring scenario analysis, variance reporting, and KPI tracking — designed to support strategic planning cycles and C-suite decision-making.

## 📊 Model Components

| Component | Description |
|---|---|
| `Scenario Analysis` | Best, base, and worst case revenue projections |
| `Variance Report` | Actual vs budget with automated flagging |
| `KPI Dashboard` | Key metrics tracking across business units |
| `Cash Flow Model` | Monthly cash flow forecasting |

## 🔍 Key Features

- Dynamic scenario toggle (Best / Base / Worst)
- Automated variance flagging (Favourable / Unfavourable)
- Rolling 12-month KPI tracking
- Executive-ready summary dashboard
- Fully linked assumptions sheet for easy updates

## 🛠️ Tools Used
- Microsoft Excel (Advanced — INDEX/MATCH, dynamic arrays, pivot tables)
- Power BI (for dashboard visualisation layer)
